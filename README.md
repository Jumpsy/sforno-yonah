# Why did Yonah run?

A class presentation on Sforno's reading of Yonah 1:3 by Jonah, Yael and Jacob.

Live slideshow: https://jumpsy.github.io/sforno-yonah/

Files in this repo:
- `index.html` is the animated slideshow
- `sforno-yonah.pptx` is the slides for PowerPoint or Google Slides
- `sforno-yonah.pdf` is the slides as a PDF
- `presentation-script.docx` is what each of us says
- `our-worksheet.docx` is our filled in worksheet

Sources are on the last slide.
